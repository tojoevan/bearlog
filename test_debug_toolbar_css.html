Debug Toolbar CSS 文件测试

✅ toolbar.css

状态: 正常加载（无 media 属性）

用途: Debug Toolbar 的主要样式

加载时机: 页面加载时立即应用

ℹ️ print.css

状态: 已定义但仅在打印时加载

用途: 打印页面时隐藏 Debug Toolbar

加载时机: 仅在打印或打印预览时加载

注意: 在正常浏览时，浏览器不会请求此文件，这是预期行为！

如何验证 print.css

  1. 按 Ctrl+P (Windows/Linux) 或 Cmd+P (Mac) 打开打印对话框
  2. 或者在浏览器开发者工具中：
    • 打开 DevTools (F12)
    • 切换到 "Rendering" 标签
    • 找到 "Emulate CSS media type"
    • 选择 "print"
  3. 此时你会看到 print.css 被加载并生效

print.css 内容

#djDebug {
    display: none !important;
}

这段 CSS 确保在打印页面时，Debug Toolbar 会被隐藏。
